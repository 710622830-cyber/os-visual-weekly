# 2026 OS 视觉设计周报

每周一 09:00 自动生成上一周的 OS 视觉设计新动态，覆盖 Apple / Huawei / vivo（及其他厂商如有必要）的 UI / 设计语言变更。

**结构**：单页 `index.html` 持续追加 weekly section，不覆盖历史——可以作为时间线档案看视觉演变。

**技术规格**：
- 单文件自包含 HTML，图片 base64 内嵌，可离线打开
- 配图**必须来自信源原文截图**（禁止 AI 生图 / CSS 重建示意）
- 所有信源 / 出处链可点击
- CSS 变量化主题、响应式 grid（`.fig` / `.figrow.g2` / `.figrow.g3`）

**更新方式**：自动化任务每周一 09:00 执行 → 追加 section → git push → GitHub Pages 自动部署。
